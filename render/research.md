# Image-edit APIs for Yardplan "Photoreal render"

Researched 2026-10-13. Prices from the providers' own pages where I could read them; anything not read on a primary page today is marked **[UNVERIFIED]**. Re-check before launch: prices and model names in this space change every few months (two of the models people still cite are already deprecated, see below).

## What the feature needs
Take a phone/drone photo or public-domain aerial of a real yard and redesign only the ground. It must keep the house, fence, shed, poles, hills, **camera, perspective and aspect ratio**, remove clutter, and add specific catalog plants and hardscape. Needs: strong image edits that keep the geometry, an input-aspect output (the yard photo is portrait 3:4), optional reference images (layout guide, walk-around style reference), and low cost per image.

Note on the sample result Austin liked (`assets/sample-render.jpg`): the quality and style are right, but it came back **16:9 from a 3:4 photo**, so the framing was cropped and re-composed. That is the main failure to guard against. The prompt says to keep the aspect ratio, and the adapters ask for `aspect_ratio: auto` / match input. Apps should still check the output dimensions.

## Recommendation
- **Primary: xAI Grok Imagine Image 2.0 edit, about $0.05 per render** (1K low: $0.04 + $0.01 input; $0.06 with a layout guide or style reference as a second input; $0.07–0.09 at medium or 2K). Reasons: it made the result Austin liked, the price is low and flat with no token maths, aspect `auto` follows the input photo, it takes multiple reference images (the overlay guide and the walk-around style reference both need this), and outputs aren't used for training. It's wired as `xai` in the Worker.
- **Fallback: FLUX.1 Kontext [pro] on fal.ai, $0.04 per render.** A different vendor, so an outage or refusal at xAI doesn't take the feature down. Kontext is the best hosted model at keeping the scene, and it's cheap with commercial use included. The catch is that it takes only one input image, so it gets the text layout hints but not the guide image or style reference. It's wired as `fal-kontext`.
- **Later / pro tier:** SDXL inpaint + ControlNet depth (or FLUX Fill + depth) for "exact geometry" when a contractor needs it: a hard mask over the yard plus depth lock. Or gpt-image with a mask when per-region edits matter. Avoid Gemini 2.5 Flash Image (already shut down) and gpt-image-1.5 (removed Dec 2026). Flux Kontext dev is non-commercial.
- **Budget example:** at the default $2/day Worker cap that's about 40 renders/day. 1,000 renders/month comes to about $50–60.
